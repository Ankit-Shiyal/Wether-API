# 🌦️ Weather App

A simple weather application that shows real-time weather data using an API.


## 📌 Features

* Search weather by city name
* Shows temperature in °C
* Displays humidity
* Displays wind speed
* Error message for invalid city

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* Fetch API
* OpenWeather API

## 📂 Project Structure

```
project-folder/
│── index.html
│── style.css
│── script.js
│── img/
│   ├── clouds.png
│   ├── humidity.png
│   └── wind-speed.png
```

## 🔑 API Used

* OpenWeather API
* You can get your API key from: https://openweathermap.org/api

## ⚙️ How It Works

* User enters city name
* App fetches data using API
* Displays:

  * Temperature
  * City Name
  * Humidity
  * Wind Speed
* Shows error if city not found

## ❌ Error Handling

* Displays "No city found" for invalid input
* Clears old data on error
